// Practice

My work moves between machine learning, quantitative markets and the study of human behaviour. The subjects differ; the habit of mind does not. Each asks how a system should decide under uncertainty, and how to tell a real signal from a convenient story.

I learn by building. Theory is tested against a working artefact, results are measured against an honest baseline, and every model is expected to explain itself.

The long-term aim is independence of thought and work that compounds: a self-directed curriculum across deep technology, economics and behaviour, applied to problems that scale.

// Projects, in depth

  1. 01 · NORTHSTAR 1st place · CodeRush 2026

    NorthStar: an offline AI tutor

    Python · SentenceTransformers · TF-IDF · FAISS · local LLM

    Question

    Can a capable study assistant work where the internet does not?

    Method

    Offline retrieval-augmented generation: FAISS and SBERT semantic search feeding a 4-bit quantised LLaMA-family model for on-device inference.

    Result

    Answers in under two seconds on a CPU. First place, Education domain, CodeRush 2026, a 24-hour national hackathon.

  2. 02 · OPENENV Meta AI OpenEnv Hackathon

    OpenENV: an enterprise decision agent

    Python · FastAPI · Pydantic · Docker · OpenEnv API

    Question

    How should an agent balance email triage, scheduling, task execution and system health when they compete?

    Method

    An RL-inspired policy layer that finds the weakest performance dimension at each step and chooses constraint-aware actions, keeping decision logic separate from LLM execution.

    Result

    Baseline scores of 0.98+ on Easy and Medium tasks and 0.90+ on Hard. Deployed with Docker to Hugging Face Spaces behind FastAPI and Gradio, following OpenEnv’s reset, step and state contract.

  3. 03 · TALENTMATCH

    TalentMatch AI: explainable ranking

    Python · scikit-learn · SentenceTransformers · NLP

    Question

    Can candidate ranking be both more accurate and easier to justify?

    Method

    Cosine similarity on SBERT embeddings combined with fifteen-plus engineered features, from TF-IDF vectors to skill-match ratios, in a weighted ensemble tuned by grid search.

    Result

    A 22% improvement in ranking correlation over a TF-IDF baseline, measured with NDCG@10 and Precision@K, with LLM-assisted, per-candidate explanations.

  4. 04 · SENTINELSENSE

    SentinelSense: anomalies in sensor streams

    Python · scikit-learn · LSTM

    Question

    How do you catch genuine faults in multivariate IoT data without drowning operators in false alarms?

    Method

    Isolation Forest, One-Class SVM and a sliding-window LSTM autoencoder, with dynamic thresholds from rolling z-scores and adaptive percentiles, and severity-scored alerting.

    Result

    False positives down 31% against fixed thresholds. On the SKAB benchmark, F1 of 0.83 for Isolation Forest and 0.87 for the LSTM autoencoder on held-out data.

  5. 05 · VALOVISION

    ValoVision: reading gameplay as behaviour

    Python · OpenCV · YOLOv8

    Question

    Can raw FPS footage be turned into reliable measures of how a player behaves?

    Method

    Frame differencing, contour analysis and a YOLOv8 model fine-tuned on more than 1,200 labelled frames, stabilised by sliding-window majority voting.

    Result

    91% event-detection precision on a held-out set, feeding kill-zone frequency, positional heatmaps and reaction-latency analysis.
